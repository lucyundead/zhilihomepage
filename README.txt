Zhi Li Academic Homepage

The static academic homepage of Zhi Li, Associate Research Fellow at Shanghai
Normal University.

Live site: https://lucyundead.github.io/zhilihomepage/

The site uses plain HTML and CSS and is published from the master branch with
GitHub Pages. Run the regression checks with:

  node --test --test-isolation=none tests/homepage.test.mjs

The CV PDF remains in files/CV_zli.pdf but is intentionally not linked from the
homepage until its content is updated.
